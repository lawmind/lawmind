earlier this session -- checked the actual ODbL 1.0 text rather than
leave it as a vague "share-alike, unclear" caveat.

Commercial use is explicitly permitted (sec 3.1). Share-alike (sec 4.4)
only attaches to PUBLICLY USING a derivative database -- internal
organisational use is explicitly exempt (sec 4.5c). Still not a
clearance -- whether LawMind's use (internal enrichment, not

call this lane isn't making -- but the facts are now precise enough for
